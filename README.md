# Мой китайский · 学习

Личный тренажёр китайского: словарь, карточки, повторение, тесты, бизнес-китайский, уроки и письмо иероглифов. Собственная копия проекта из ChatGPT Sites, версия 38 от 11 ноября 2026 года.

## Запуск без ChatGPT

1. Установите Node.js 22.13 или новее и Git.
2. Скачайте репозиторий:
   ```sh
   git clone https://github.com/y141989git/my-chinese-app.git
   cd my-chinese-app
   npm start
   ```
3. Откройте **http://127.0.0.1:3000**. Используйте этот адрес постоянно: браузерное хранилище привязано к адресу.
4. Чтобы остановить сервер, нажмите Ctrl+C. Для следующего запуска снова выполните `npm start`.

Для автономного режима `npm install`, сборка, аккаунт ChatGPT и ключи API не нужны. Сервер использует стандартную библиотеку Node.js. Словарь, исходные строки, библиотека Hanzi Writer и данные черт включены в репозиторий. После скачивания можно работать без интернета; озвучивание зависит от голосов и возможностей браузера/ОС.

Это личный сервер на одном компьютере. Он слушает только 127.0.0.1 и не предназначен для публикации в интернете или доступа с телефона. Обмен между устройствами — через экспорт/импорт. Исходный сервер Sites сохранён для дальнейшей разработки, его инструкция — [README-SITES.md](README-SITES.md). Старый шаблон требует инфраструктуры Sites; для независимого запуска используйте команды выше.

## Перенос личного прогресса из Work

**Личный прогресс из облачной базы ещё не экспортирован.** Исходный репозиторий не содержит пользовательские записи D1, IndexedDB и localStorage вашего браузера. Копирование кода не переносит эти данные.

1. На оригинальном сайте войдите в свой аккаунт, нажмите синхронизацию и дождитесь «Сохранено в аккаунте». Не вносите изменения во время экспорта.
2. Откройте «Источники и перенос» → «Экспорт всей базы JSON». Сохраните файл вне репозитория. Этот старый экспорт переносит словарь, карточки и историю, но **не результаты письма и не список удалений**.
3. Для полного переноса, включая письмо, откройте на компьютере инструменты разработчика браузера → Console. Просмотрите файл `tools/export-from-work.js`, скопируйте его содержимое и выполните на вкладке оригинального сайта. Скрипт только читает данные сайта и скачивает `my-chinese-work-export.json`. Он требует входа в аккаунт и успешной синхронизации. При ошибке экспорт не считается завершённым. Не отключайте защиту браузера от вставки непроверенного кода.
4. Запустите независимую копию. Откройте «Источники и перенос» → «Импорт JSON / CSV / TSV», выберите скачанный JSON.
5. Проверьте избранное, «Помню», повторение, свои записи и рисунки в разделе письма. Дождитесь «Сохранено» и перезапустите сервер для проверки сохранения.

В независимой копии стандартный JSON-экспорт дополнен письмом и списком удалений. Импорт объединяет данные, а не заменяет всё содержимое. Не импортируйте одну и ту же копию многократно: старая логика объединения может повторять записи истории. Настройки интерфейса (положение меню, фраза дня) остаются в браузере и в учебный экспорт не входят.

## Резервное копирование

- В разделе «Источники и перенос» регулярно скачивайте JSON: он подходит для переноса на другой компьютер.
- Сервер сохраняет прогресс в `.local-data/progress.json`. Остановите сервер и скопируйте всю папку `.local-data/` в надёжное место. Для восстановления верните папку при остановленном сервере, затем откройте сайт в новом профиле браузера: старое браузерное состояние иначе может объединиться с восстановленным.
- Прогресс, личные экспорты и секреты исключены через `.gitignore`. Не добавляйте их в Git вручную.
- После изменений кода проверяйте `git diff`, делайте commit и push. GitHub хранит загруженный код; отдельные резервные копии прогресса всё равно нужны.

## Развитие

Правьте `public/index.html`, `public/app.js`, `public/business.js`, `public/cloud.js`. Перезапускайте сервер после изменения серверного кода, обновляйте страницу после изменения интерфейса. Не редактируйте многомегабайтные JSON без резервной копии. Лицензия данных черт: `public/hanzi/ARPHICPL.TXT`; сохраняйте включённые уведомления об авторстве. Общая лицензия проекта не назначена.

В исходниках сохранён `.openai/hosting.json` с идентификатором старого сайта. Автономный сервер его не использует. Не запускайте публикацию Sites, если не собираетесь менять оригинальный сайт.
